# homebrew-tap
Homebrew formulae and casks for YuhuanStudio

```sh
brew install --cask yuhuanstudio/tap/yunaudio   # YunAudio
brew install yuhuanstudio/tap/yunshu             # Yunshu (local LLM/VLM inference server, Apple Silicon)
```

Upgrade later with:

```sh
brew upgrade --cask yunaudio
brew upgrade yunshu
```
